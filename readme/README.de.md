**Mit einem Klick übersetzen, Seite an Seite lesen.** Das Zotero-Plugin von Equalang unterstützt die Übersetzung von Dokumenten wie PDFs sowie die Auswahlübersetzung: Ein Rechtsklick auf einen Anhang genügt, um die gesamte Literatur zu übersetzen; die Übersetzung behält das Originallayout bei und wird als Anhang unter dem Originaleintrag abgelegt. Wird Text im Reader markiert, erscheinen Übersetzung und Worterklärungen sofort in einem Pop-up-Fenster.

![Original links, Übersetzung rechts; beim Markieren eines Wortes erscheint die Erklärung sofort im Pop-up-Fenster](../images/reader-bilingual.png)

## Funktionen

- **Dokumentübersetzung**: Ein Rechtsklick auf einen PDF-, Word-, PowerPoint- oder Excel-Anhang genügt, um ihn zu übersetzen. Die Übersetzung behält das Originallayout bei und wird als Anhang unter dem Originaleintrag abgelegt; für PDFs lässt sich auch eine zweisprachige Version erstellen, um Original und Übersetzung Seite an Seite zu lesen.
- **Auswahlübersetzung**: Text im Reader markieren und die Übersetzung erscheint sofort in einem Pop-up-Fenster; bei einzelnen Wörtern werden zudem Definitionen, Lautschrift und Beispielsätze angezeigt.
- **Hintergrundübersetzung**: Zotero kann jederzeit beendet werden; unvollständige Aufgaben werden beim nächsten Start fortgesetzt und die Übersetzung wird weiterhin dem Originaleintrag hinzugefügt.
- **Gemeinsames Guthaben mit der Website**: Vor Beginn der Dokumentübersetzung werden die geschätzten Credits und das aktuelle Guthaben angezeigt; abgebrochene Aufgaben kosten keine Credits.

## Installation

1. **Plugin-Datei herunterladen**: Zur [Releases-Seite](https://github.com/equalang/equalang-zotero-plugin/releases/latest) gehen und die neueste Version von `equalang.xpi` herunterladen; sie muss nicht entpackt werden.
2. **Plugin-Verwaltung in Zotero öffnen**: Im Zotero-Menü „Werkzeuge → Plugins“ wählen.
3. **Aus Datei installieren**: Auf das Zahnrad-Symbol oben rechts klicken, „Install Plugin From File…“ wählen und die heruntergeladene Datei auswählen; alternativ kann die Datei direkt in das Plugin-Fenster gezogen werden.
4. **Bei Equalang anmelden**: Nach der Installation öffnet sich ein Willkommensfenster. Auf „Anmelden oder registrieren“ klicken und die Anmeldung im Browser abschließen. Neue Konten erhalten kostenlose Credits geschenkt.

Danach aktualisiert sich das Plugin automatisch mit Zotero; Updates können auch manuell über das Zahnrad-Menü unter „Werkzeuge → Plugins“ gesucht werden.

## Verwendung

- **Dokumente übersetzen**: Rechtsklick auf einen Eintrag oder Anhang, „Mit Equalang übersetzen…“ wählen, Zielsprache sowie geschätzte Credits bestätigen und starten. Der Fortschritt wird rechts im Bereich „Equalang“ angezeigt oder kann unter „Werkzeuge → Equalang → Übersetzungsaufgaben…“ eingesehen werden.

  ![Equalang-Übersetzung im Kontextmenü](../images/context-menu.png)

- **Seite an Seite lesen**: Die zweisprachige Version öffnen und im Reader „Ansicht → Seiten → Ungerade“ wählen, damit Original und Übersetzung nebeneinander angezeigt werden.
- **Auswahlübersetzung**: Einfach Text im Reader markieren. In den Einstellungen kann auch zu „Zuerst Schaltfläche „Übersetzen“ anzeigen“ gewechselt werden, um erst nach dem Klicken zu übersetzen.
- **Einstellungen**: Unter „Werkzeuge → Equalang → Einstellungen...“ lässt sich festlegen, in welche Sprache übersetzt werden soll, ob PDFs zweisprachig oder nur als Übersetzung erstellt werden, wo übersetzte Dateien gespeichert werden, ob „Übersetzung nach Fertigstellung öffnen“ aktiviert sein soll und ob das Formellayout in PDFs optimiert werden soll (verbraucht zusätzliche Credits).

## Häufig gestellte Fragen

**Welche Zotero-Versionen und Betriebssysteme werden unterstützt?**

Unterstützt Zotero 7, 8, 9 und 10 unter Windows und macOS.

**Wie funktioniert die Abrechnung?**

Die Installation des Plugins ist kostenlos. Die Übersetzung teilt sich das Guthaben mit der Equalang-Website und rechnet nach den [Preisen der Website](https://equalang.com/de/pricing?utm_source=github) ab. Vor Beginn einer Dokumentübersetzung werden die geschätzten Credits und das aktuelle Guthaben angezeigt; abgebrochene Aufgaben kosten keine Credits. Neue Konten erhalten kostenlose Credits.

**Wo werden die übersetzten Dateien gespeichert?**

Bei der Dokumentübersetzung wird die übersetzte Datei standardmäßig als Anhang unter dem Originaleintrag abgelegt und mit Zotero synchronisiert; in den Einstellungen kann sie stattdessen in einem lokalen Ordner gespeichert und mit dem Eintrag verknüpft werden (nur unter „Meine Bibliothek“).
