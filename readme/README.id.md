**Terjemahkan sekali klik, baca berdampingan.** Plugin Zotero dari Equalang mendukung terjemahan dokumen seperti PDF serta terjemahan teks terpilih: cukup klik kanan lampiran untuk menerjemahkan seluruh literatur, terjemahan tetap mempertahankan tata letak asli dan disematkan sebagai lampiran di bawah literatur asli. Di pembaca, saat memilih teks, terjemahan dan arti kata langsung muncul di jendela sembulan.

![Teks asli di kiri, terjemahan di kanan; saat memilih kata, artinya langsung muncul di jendela sembulan](../images/reader-bilingual.png)

## Fitur

- **Terjemahan dokumen**: Cukup klik kanan pada lampiran PDF, Word, PowerPoint, atau Excel untuk menerjemahkannya. Terjemahan tetap mempertahankan tata letak asli dan disematkan sebagai lampiran di bawah literatur asli; format PDF bahkan dapat dibuat menjadi file dwibahasa untuk membaca teks asli dan terjemahan secara berdampingan.
- **Terjemahan teks terpilih**: Pilih teks di pembaca, terjemahan akan langsung muncul di jendela sembulan; saat memilih kata, definisi, transkripsi fonetik, dan contoh kalimat juga akan disertakan.
- **Terjemahan di latar belakang**: Anda dapat keluar dari Zotero kapan saja; tugas yang belum selesai akan dilanjutkan saat Zotero dibuka kembali, dan file terjemahan tetap akan ditambahkan ke literatur asli.
- **Saldo kredit bersama dengan situs web**: Sebelum penerjemahan dokumen dimulai, perkiraan kredit yang dibutuhkan dan saldo saat ini akan ditampilkan; tugas yang dibatalkan tidak memotong kredit.

## Pemasangan

1. **Unduh file plugin**: Buka [halaman Rilis](https://github.com/equalang/equalang-zotero-plugin/releases/latest), unduh versi terbaru `equalang.xpi`, tidak perlu mengekstraknya.
2. **Buka pengelola plugin Zotero**: Di menu Zotero, pilih "Perkakas → Plugins".
3. **Pasang dari file**: Klik ikon roda gigi di kanan atas, pilih "Install Plugin From File…", lalu pilih file yang baru saja Anda unduh; Anda juga dapat langsung menyeret file ke jendela plugin ini.
4. **Masuk ke Equalang**: Jendela selamat datang akan terbuka setelah terpasang; klik "Masuk atau Daftar" lalu selesaikan proses masuk di browser Anda. Akun baru mendapatkan kredit gratis.

Setelah itu, plugin akan diperbarui secara otomatis bersama Zotero; Anda juga dapat memeriksa pembaruan secara manual di menu roda gigi di "Perkakas → Plugins".

## Penggunaan

- **Menerjemahkan dokumen**: Klik kanan pada literatur atau lampiran, pilih "Terjemahkan dengan Equalang…", konfirmasikan bahasa target dan perkiraan kredit lalu mulai. Progres ditampilkan di kolom "Equalang" di sebelah kanan, atau dapat dilihat di "Perkakas → Equalang → Tugas Terjemahan…".

  ![Terjemahan Equalang di menu klik kanan](../images/context-menu.png)

- **Membaca berdampingan**: Buka versi dwibahasa, lalu di pembaca pilih "Lihat → Spreads → Odd" agar teks asli dan terjemahan tampil berdampingan.
- **Terjemahan teks terpilih**: Cukup pilih teks di pembaca. Anda juga dapat mengubah pengaturan menjadi "Tampilkan tombol Terjemahkan terlebih dahulu" agar terjemahan baru berjalan setelah tombol diklik.
- **Pengaturan**: Di "Perkakas → Equalang → Pengaturan…", Anda dapat menentukan bahasa terjemahan, memilih format PDF dwibahasa atau hanya terjemahan, lokasi penyimpanan terjemahan, apakah akan mengaktifkan "Buka terjemahan setelah selesai", serta apakah ingin mengoptimalkan tata letak rumus pada PDF (mengonsumsi kredit tambahan).

## Pertanyaan yang Sering Diajukan

**Versi Zotero dan sistem operasi apa saja yang didukung？**

Mendukung Zotero 7, 8, 9, dan 10, serta dapat digunakan di Windows dan macOS.

**Bagaimana biayanya dihitung？**

Pemasangan plugin ini gratis. Penerjemahan menggunakan saldo kredit bersama dengan situs web Equalang dan dipotong sesuai [harga di situs web](https://equalang.com/id/pricing?utm_source=github). Sebelum dokumen diterjemahkan, perkiraan kredit yang dibutuhkan dan saldo saat ini akan ditampilkan; tugas yang dibatalkan tidak memotong kredit. Akun baru mendapatkan kredit gratis.

**Di mana file terjemahan disimpan？**

File hasil terjemahan dokumen secara default akan menjadi lampiran di bawah literatur asli dan disinkronkan dengan Zotero; Anda juga dapat mengubah pengaturan untuk menyimpannya ke folder di komputer, lalu menautkannya ke literatur asli (hanya untuk "Perpustakaanku").
