**一键翻译，双屏对照。** 意扣（Equalang）的 Zotero 插件，支持 PDF 等文档翻译以及划词翻译：右键附件就能翻译整篇文献，译文保留原有排版，作为附件放在原文献下；在阅读器里选中文字，译文和释义马上出现在悬浮框里。

![左边原文、右边译文；选中单词，释义马上出现在悬浮框里](../images/reader-bilingual.png)

## 功能

- **文档翻译**：右键 PDF、Word、PowerPoint 或 Excel 附件即可翻译。译文保留原有排版，作为附件放在原文献下；PDF 还能生成双语对照版，原文和译文左右对照着读。
- **划词翻译**：在阅读器里选中文字，译文马上出现在悬浮框里；选中单词时还会给出释义、音标和例句。
- **后台翻译**：可以随时退出 Zotero，未完成的任务会在下次启动时继续，译文仍会添加到原文献下。
- **与网站共用积分**：文档翻译开始前显示预计积分和当前余额，取消的任务不扣积分。

## 安装

1. **下载插件文件**：前往 [Releases 页面](https://github.com/equalang/equalang-zotero-plugin/releases/latest)，下载最新版本的 `equalang.xpi`，不需要解压。
2. **打开 Zotero 的插件管理**：在 Zotero 的菜单里选择“工具 → 插件”。
3. **从文件安装**：点右上角的齿轮图标，选择“Install Plugin From File…”，再选中刚下载的文件；也可以直接把文件拖进这个插件窗口。
4. **登录意扣**：装好后会打开欢迎窗口，点“登录或注册”，在浏览器里完成登录。新账号赠送积分。

之后插件会随 Zotero 自动更新，也可以在“工具 → 插件”的齿轮菜单里手动检查更新。

## 使用

- **翻译文档**：在文献或附件上右键，选择“用意扣翻译文档…”，确认目标语言和预计积分后开始。进度显示在右侧的“意扣”一栏里，也可以在“工具 → 意扣 → 翻译任务…”中查看。

  ![右键菜单里的意扣翻译](../images/context-menu.png)

- **左右对照阅读**：打开双语对照版，在阅读器中选择“查看 → 平铺 → 奇数页起始”，原文和译文就左右并排。
- **划词翻译**：在阅读器里选中文字即可。也可以在设置里改为先显示“翻译”按钮，点了再翻译。
- **设置**：在“工具 → 意扣 → 设置…”里，可以设置译成哪种语言、PDF 要双语对照还是只要译文、译文存在哪里、翻译完成后是否打开译文，以及是否优化 PDF 里的公式排版（会多扣积分）。

## 常见问题

**支持哪些 Zotero 版本和系统？**

支持 Zotero 7、8、9 和 10，在 Windows 和 macOS 上都可以使用。

**怎么收费？**

插件免费安装。翻译与意扣网站共用一个积分余额，按[网站的价格](https://equalang.com/zh-CN/pricing?utm_source=github)扣积分。文档翻译开始前会显示预计积分和当前余额，取消的任务不扣积分。新账号赠送积分。

**译文文件保存在哪里？**

文档翻译的译文文件默认作为附件放在原文献下，随 Zotero 同步；也可以在设置里改为保存到电脑上的文件夹，再链接到原文献（仅限“我的文库”）。
