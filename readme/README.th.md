## คุณสมบัติ

- **แปลเอกสาร**: คลิกขวาที่ไฟล์แนบ PDF, Word, PowerPoint หรือ Excel เพื่อแปลได้ทันที ฉบับแปลจะคงการจัดหน้าเดิมไว้และบันทึกเป็นไฟล์แนบใต้รายการต้นฉบับ สำหรับ PDF ยังสามารถสร้างฉบับเทียบคู่สองภาษาเพื่ออ่านเปรียบเทียบต้นฉบับและคำแปลซ้ายขวาได้อีกด้วย
- **แปลข้อความที่เลือก**: เมื่อเลือกข้อความในโปรแกรมอ่าน คำแปลจะปรากฏในหน้าต่างลอยทันที และเมื่อเลือกคำเดี่ยว ๆ จะมีทั้งคำจำกัดความ สัทอักษร และประโยคตัวอย่างแสดงให้ด้วย
- **แปลในเบื้องหลัง**: สามารถปิด Zotero ได้ตลอดเวลา งานที่ยังไม่เสร็จจะดำเนินการต่อโดยอัตโนมัติเมื่อเปิดโปรแกรมครั้งถัดไป และไฟล์แปลจะยังคงถูกเพิ่มเข้าไปใต้รายการต้นฉบับ
- **ใช้เครดิตร่วมกับเว็บไซต์**: ก่อนเริ่มแปลเอกสาร ระบบจะแสดงจำนวนเครดิตที่คาดว่าจะต้องใช้และยอดคงเหลือปัจจุบัน งานที่ยกเลิกจะไม่ถูกหักเครดิต

## การติดตั้ง

1. **ดาวน์โหลดไฟล์ปลั๊กอิน**: ไปที่ [หน้า Releases](https://github.com/equalang/equalang-zotero-plugin/releases/latest) แล้วดาวน์โหลด `equalang.xpi` เวอร์ชันล่าสุด โดยไม่ต้องแตกไฟล์
2. **เปิดหน้าต่างจัดการปลั๊กอินของ Zotero**: ไปที่เมนูของ Zotero แล้วเลือก “เครื่องมือ → Plugins”
3. **ติดตั้งจากไฟล์**: คลิกไอคอนรูปฟันเฟืองที่มุมขวาบน เลือก “Install Plugin From File…” แล้วเลือกไฟล์ที่คุณเพิ่งดาวน์โหลด หรือจะลากไฟล์เข้ามาวางในหน้าต่างปลั๊กอินนี้โดยตรงก็ได้
4. **เข้าสู่ระบบ Equalang**: เมื่อติดตั้งเสร็จแล้ว หน้าต่างต้อนรับจะเปิดขึ้นมา ให้คลิก “เข้าสู่ระบบหรือลงทะเบียน” แล้วเข้าสู่ระบบในเบราว์เซอร์ของคุณให้เรียบร้อย บัญชีใหม่รับฟรีเครดิต

หลังจากนี้ ปลั๊กอินจะอัปเดตอัตโนมัติตาม Zotero หรือจะตรวจสอบการอัปเดตด้วยตนเองได้ที่เมนูรูปฟันเฟืองใน “เครื่องมือ → Plugins”

## วิธีใช้งาน

- **แปลเอกสาร**: คลิกขวาที่รายการเอกสารหรือไฟล์แนบ เลือก “แปลเอกสารด้วย Equalang…” ยืนยันภาษาปลายทางและเครดิตที่คาดว่าจะต้องใช้เพื่อเริ่มแปล ความคืบหน้าจะแสดงในส่วน “Equalang” ทางด้านขวา หรือตรวจสอบได้ที่ “เครื่องมือ → Equalang → งานแปล…”

  ![การแปลด้วย Equalang ในเมนูคลิกขวา](../images/context-menu.png)

- **อ่านเปรียบเทียบสองภาษา**: เมื่อเปิดฉบับเทียบคู่สองภาษา ในโปรแกรมอ่านให้เลือก “View → Spreads → Odd” เพื่อให้ต้นฉบับและคำแปลแสดงผลคู่ขนานกันทางซ้ายและขวา
- **แปลข้อความที่เลือก**: เพียงเลือกข้อความในโปรแกรมอ่าน หรือสามารถเปลี่ยนในการตั้งค่าเป็น “แสดงปุ่ม "แปล" ก่อน” เพื่อคลิกก่อนแล้วจึงแปล
- **การตั้งค่า**: ใน “เครื่องมือ → Equalang → Settings…” สามารถกำหนดภาษาปลายทาง เลือกว่า PDF จะเป็นแบบเทียบคู่หรือเฉพาะคำแปล ตำแหน่งที่จัดเก็บไฟล์ฉบับแปล “เปิดไฟล์คำแปลเมื่อเสร็จสิ้น” หรือไม่ รวมถึงเลือกว่าจะปรับปรุงการจัดหน้าสูตรใน PDF หรือไม่ (ซึ่งจะหักเครดิตเพิ่ม)

## คำถามที่พบบ่อย

**รองรับ Zotero เวอร์ชันใดและระบบปฏิบัติการใดบ้าง?**

รองรับ Zotero 7, 8, 9 และ 10 โดยสามารถใช้งานได้ทั้งบน Windows และ macOS

**มีค่าใช้จ่ายอย่างไร?**

ปลั๊กอินติดตั้งได้ฟรี การแปลใช้ยอดเครดิตร่วมกับเว็บไซต์ Equalang และหักเครดิตตาม[ราคาบนเว็บไซต์](https://equalang.com/th/pricing?utm_source=github) ก่อนเริ่มแปลเอกสาร ระบบจะแสดงยอดเครดิตคงเหลือและจำนวนเครดิตที่คาดว่าจะต้องใช้ งานที่ยกเลิกจะไม่ถูกหักเครดิต บัญชีใหม่รับฟรีเครดิต

**ไฟล์ฉบับแปลจะถูกบันทึกไว้ที่ใด?**

ตามค่าเริ่มต้น ไฟล์ฉบับแปลจะถูกแนบไว้ใต้รายการเดิมและซิงค์ผ่าน Zotero หรือสามารถเปลี่ยนการตั้งค่าให้บันทึกลงในโฟลเดอร์บนคอมพิวเตอร์ของคุณแล้วลิงก์กลับมายังรายการเดิมได้ (เฉพาะใน “ไลบรารีของฉัน”)
